# Contributing

Contributions that improve accessibility, recommendation transparency,
documentation, tests, or the career catalog are welcome.

## Development workflow

1. Fork the repository and create a focused branch.
2. Create a virtual environment.
3. Install development dependencies with `pip install -r requirements-dev.txt`.
4. Make a small, documented change.
5. Run `python -m compileall -q .` and `pytest -q`.
6. Open a pull request that explains the problem, approach, and verification.

Do not commit Discord tokens, Gemini keys, personal assessment data, or local
database files. Career information should be phrased carefully and should not
promise employment, income, or a guaranteed outcome.
